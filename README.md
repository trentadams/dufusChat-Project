# Dufus Chat

## Synopsis
This project aims to create a JavaFX-based chat application that enables real-time messaging between two or more users. The system consists of multiple client programs and a centralized server program that handles message routing and client management. The client application features a user-friendly graphical interface built with JavaFX, and every user will be represented by an object containing their name and a unique client ID.

## Motivation
This project was developed for my Software Development course at Southwest Technical College.
