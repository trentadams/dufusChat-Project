# Dufus Chat

## Synopsis
DufusChat aims to create a JavaFX-based chat application that enables real-time messaging between two or more users. The system consists of multiple client programs and a centralized server program that handles message routing and client management. The client application features a user-friendly graphical interface built with JavaFX, and every user will be represented by an object containing their name and a unique client ID.

### Features
- Unique User ID Generation using User.java.
- User selected display names.
- Straight-forward UI.
- Server-wide messages broadcasting when a user leaves/joins the chat.
